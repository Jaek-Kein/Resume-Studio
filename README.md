# Resume Studio v3 — 정적 이력서 빌더

브라우저에서 필요한 이력서 섹션만 골라 작성하고, 여러 템플릿으로 미리본 뒤 A4 PDF로 저장하는 정적 웹앱입니다. 서버나 빌드 과정이 필요하지 않습니다.

## 실행
압축을 풀고 `index.html`을 더블클릭하면 됩니다. 웹폰트는 인터넷 연결이 있을 때 로드됩니다.

## v3 주요 기능
- 6개 템플릿: 한국 표준형 / ATS / 미니멀 / 모던 / 컴팩트 / Europass형
- 작성 패널 ↔ 미리보기 패널 좌우 반전 및 설정 저장
- 웹폰트: Pretendard, Noto Sans KR, Noto Serif KR, IBM Plex Sans KR, Nanum Gothic, Nanum Myeongjo, Inter 등
- 사용자 지정 웹폰트 CSS URL + font-family 이름 지원
- PDF 출력 전 `document.fonts.ready`로 웹폰트 로딩 대기
- 증명사진 업로드
- 기본 정보 + 영문 이름/국적/성별 등 선택 필드
- 한국형 특수 정보: 병역 상태, 군별, 계급, 병과/특기, 복무기간, 전역/면제 사유
- 선택형 민감 정보: 보훈, 장애, 취업보호, 운전면허, 해외여행 결격사유
- 대폭 확장된 선택 섹션
  - 직무 목표 / 자기소개 / 핵심 역량
  - 경력 / 인턴 / 프리랜스 / 프로젝트
  - 학력 / 기술 / 자격·인증 / 어학
  - 병역 / 한국형 추가 사항
  - 수상 / 대외활동·동아리 / 봉사 / 교육·부트캠프
  - 연구·논문 / 특허 / 오픈소스 / 해외 경험 / 추천인
  - 취미·관심사 / 사용자 정의 섹션
- 섹션별 On/Off + Drag & Drop 순서 변경
- 개발자 / 신입 / 한국형 전체 / 최소 구성 프리셋
- 실시간 미리보기
- 글자 크기 / 줄 간격 / A4 여백 / 포인트 컬러
- localStorage 자동 저장
- v2 데이터 자동 마이그레이션
- JSON 백업/복원
- 브라우저 인쇄 엔진 기반 PDF 저장

## PDF 저장
`PDF 저장 / 인쇄` 버튼을 누르면 선택된 웹폰트의 로딩이 완료된 뒤 브라우저 인쇄창을 엽니다.
권장 인쇄 설정: A4 / 배율 100% / 여백 없음 / 배경 그래픽 켬.

## 개인정보 관련
보훈·장애·성별·생년월일 같은 항목은 제출처에서 실제로 요구하는 경우에만 켜서 사용하는 것을 권장합니다. 앱은 입력 데이터를 서버로 전송하지 않고 브라우저 `localStorage`에 저장합니다.
